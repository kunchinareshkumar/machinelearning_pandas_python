## 📖 Learning Topics

### 01. Introduction, Installation & Setup
**Level:** Beginner

Introduction to Pandas, its applications, installation, environment setup, importing libraries, and getting started with Jupyter Notebook.

### 02. Series - The 1-D Data Structure
**Level:** Beginner

Creating Series, indexing, slicing, accessing elements, vectorized operations, and Series properties.

### 03. DataFrame - The 2-D Data Structure
**Level:** Beginner

Creating DataFrames, rows and columns, indexing, modifying data, and understanding tabular structures.

### 04. Reading & Writing Data (I/O)
**Level:** Beginner

Working with CSV, Excel, JSON, SQL, and Parquet files. Importing, exporting, and managing datasets.

### 05. Inspecting & Understanding Data
**Level:** Beginner

Exploring datasets using `head()`, `tail()`, `info()`, `describe()`, `shape`, `dtypes`, and statistical summaries.

### 06. Selecting, Indexing & Filtering
**Level:** Beginner

Selecting rows and columns using `loc`, `iloc`, boolean conditions, `query()`, and conditional filtering.

### 07. Data Types & Type Conversion
**Level:** Beginner

Understanding Pandas data types, type casting, `astype()`, `to_numeric()`, and data type validation.

### 08. Handling Missing Data
**Level:** Beginner

Identifying and managing null values using `isna()`, `notna()`, `fillna()`, `dropna()`, and interpolation.

### 09. Data Cleaning: Duplicates, Renaming, Replacing & Outliers
**Level:** Beginner

Cleaning datasets, removing duplicates, renaming columns, replacing invalid values, and detecting outliers using statistical techniques.

### 10. Column Operations: assign, apply, map, where, cut
**Level:** Intermediate

Creating derived columns, transforming data, conditional operations, custom functions, and binning numerical values.

### 11. Working with Text Data (.str accessor)
**Level:** Intermediate

String manipulation, text cleaning, searching, extracting patterns, splitting, replacing, and regular expressions.

### 12. Date & Time Series Basics
**Level:** Intermediate

Datetime conversion, extracting date components, filtering by dates, resampling, and time-based analysis.

### 13. Sorting, Ranking & Top-N
**Level:** Intermediate

Sorting values, sorting indexes, ranking records, and retrieving top or bottom observations.

### 14. GroupBy & Aggregation (Split-Apply-Combine)
**Level:** Intermediate

Grouping datasets, aggregating values, calculating statistics, and applying custom aggregation functions.

### 15. Combining Data: concat, merge, join
**Level:** Intermediate

Combining multiple DataFrames using concatenation, SQL-style joins, merge operations, and index-based joins.

### 16. Reshaping: pivot, melt, stack, crosstab, dummies
**Level:** Intermediate

Restructuring datasets, pivot tables, wide-to-long transformations, cross-tabulations, and categorical encoding.

### 17. MultiIndex (Hierarchical Indexing)
**Level:** Advanced

Working with hierarchical indexes, multiple index levels, advanced selection, and index restructuring.

### 18. Window Functions: rolling, expanding, ewm, shift
**Level:** Advanced

Moving averages, cumulative calculations, exponentially weighted statistics, lag features, and time-series transformations.

### 19. Categorical Data
**Level:** Advanced

Managing categorical variables, ordered categories, category conversion, and memory-efficient data representation.

### 20. Data Visualization with Pandas
**Level:** Intermediate

Creating line charts, bar charts, histograms, scatter plots, box plots, and other visualizations using Pandas and Matplotlib.

### 21. Performance & Memory Optimisation
**Level:** Advanced

Optimizing DataFrame operations, efficient data types, vectorization, chunk processing, and memory usage reduction.

### 22. Advanced Techniques: Method Chaining, pipe, Styler, Copy-on-Write
**Level:** Advanced

Building readable data pipelines, reusable transformations, DataFrame styling, and understanding Copy-on-Write behavior.

### 23. Mini Project: End-to-End Sales Analysis
**Level:** Project

A practical data analysis project covering data loading, cleaning, transformation, aggregation, visualization, and business insights.

### 24. Practice Exercises & Interview Questions
**Level:** Project

Hands-on coding challenges, data manipulation exercises, real-world problem-solving, and Pandas interview preparation.
